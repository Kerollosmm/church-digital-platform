بيئة الاختبار والتشغيل المحلي

منصة متكاملة لاختبار كافة مسارات وتدفقات منظومة الكنيسة الرقمية عبر ثلاث بوابات مخصصة، مع فحص حي لحالة قاعدة بيانات Supabase ودوال Deno Edge Functions ومحاكي مدفوعات Paymob.

🚪 بوابات المنظومة الثلاث

👤 بوابة المخدومين والرعية
USER

تطبيق المخدومين لحجز مواعيد القداسات والخدمات، واختيار الخدمات الإضافية، وسداد الرسوم عبر Paymob، وإرسال الشكاوى المشفرة والتطوع في الأنشطة.

  • استعراض المواعيد والسعة المتاحة (v_available_slots)
  • حجز المواعيد مع قفل المقعد 20 دقيقة (book_slot)
  • إرسال الشكاوى بتشفير pgcrypto (submit_complaint_secure)
  • دفع إلكتروني عبر بوابة Paymob Checkout
دخول بوابة المخدومين ←
⚙️ لوحة تحكم إدارة الكنيسة
ADMIN

لوحة السكرتارية والآباء الكهنة لمراجعة الحجوزات المعلقة، وتأكيدها بعد المكالمة الهاتفية، والحجز النقدي المباشر، ومتابعة رسائل WhatsApp Outbox.

  • طابور مراجعة الحجوزات الهاتفية (AWAITING_CALL)
  • تأكيد ورفض الحجوزات والحجز النقدي (manual_book)
  • فك تشفير وقراءة شكاوى المخدومين (decrypt_complaint)
  • مراقبة طابور الرسائل وإعادة الإرسال (event_outbox)
دخول لوحة الإدارة ←
⚡ غرفة القيادة والحوكمة العليا
SUPER_ADMIN

بوابة الحوكمة والتحكم الأمني لإدارة صلاحيات المستخدمين، ومطالعة سجل التدقيق الأمني (Audit Log)، والتقارير المالية، وفحص سلامة النظام.

  • إدارة وتعيين أدوار المستخدمين عبر قناة الخدمة الآمنة
  • سجل تدقيق العمليات غير القابل للتعديل (audit_log)
  • التقارير والتحليلات المالية الشهرية وتصدير CSV
  • تشغيل محرك الفحص الأمني (diagnostic-engine)
