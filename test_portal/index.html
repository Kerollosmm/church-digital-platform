👤 تطبيق المستخدم (User App)

شعب الكنيسة

واجهة مخصصة لشعب الكنيسة لحجز مواعيد القداسات والخدمات، تتبع حالة الحجز (AWAITING_CALL / CONFIRMED)، تقديم الشكاوى المشفرة، وقراءة الإعلانات.

الميزات المتاحة:
  • حجز المقاعد بالتزامن الآمن (Slot Lock)
  • سجل الحجوزات وإلغاء الحجز
  • الشكاوى المشفرة بـ PGCrypto
  • الإعلانات والأسئلة الشائعة
حسابات تجريبية سريعة:
🚀 فتح تطبيق المستخدم

⛪ تطبيق الخدام (Admin Portal)

الخدام والكهنة

لوحة الإدارة والتشغيل للخدام والكهنة لمعالجة الحجوزات بعد الاتصال التليفوني، الحجز اليدوي، جدولة المواعيد، ونشر الإعلانات.

الميزات المتاحة:
  • طابور مراجعة الحجوزات هاتفياً (Order Processing)
  • التحقق من رمز المرور الإداري (Admin PIN)
  • الحجز اليدوي وتوسيع السعة الطارئ
  • إدارة المواعيد والإعلانات وصندوق الشكاوى
حسابات تجريبية سريعة:
🚀 فتح لوحة المسؤول (Admin)

🛡️ مسؤول النظام (Super Admin)

مسؤول النظام العام

لوحة الإشراف العليا للتحكم الكامل في أدوار المستخدمين (RBAC)، مراقبة طوابير WhatsApp و FCM، فحص أسرار الخزنة ودوال Edge Functions.

الميزات المتاحة:
  • تعديل الأدوار (USER / ADMIN / SUPER_ADMIN)
  • إعادة تعيين رموز PIN الإدارية
  • مراقبة وإعادة إرسال أحداث Outbox المتعثرة
  • فحص أسرار Vault واختبار دوال Edge Functions
حساب مسؤول النظام العام:
🚀 فتح لوحة Super Admin
