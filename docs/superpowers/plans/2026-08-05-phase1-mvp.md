# Phase 1 — MVP: Portal + Booking + Payments + WhatsApp + Paid Videos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the Phase 1 MVP (weeks 3–6): parishioner portal (schedule/priests/FAQ/announcements/encrypted complaints), event & funeral booking with 20-min slot locks, Paymob payments with HMAC-verified idempotent webhooks and nightly reconciliation, WhatsApp template messaging via outbox + opt-in, and paid unlisted YouTube video access.

**Architecture:** Supabase-first. SQL (views, SECURITY DEFINER RPCs, triggers, CHECK constraints, pg_cron) owns all money/booking state; Deno Edge Functions own all external HTTP (Paymob Accept API + webhooks, Meta WhatsApp Cloud API, YouTube Data API via OAuth2) and hold all secrets (A11). Slot lock = `SELECT FOR UPDATE` on the slot row + active-booking count vs `capacity` inside `book_slot()` (no Redis). RLS is the only security boundary; apps hold only anon key + user JWT. Flutter mobile + Flutter Web admin talk to PostgREST/Realtime directly.

**Tech Stack:** Supabase (PostgreSQL 16, Auth phone OTP, Realtime, Edge Functions Deno 2, pg_cron, pg_net, supabase_vault), Paymob Accept API (unified checkout, HMAC webhooks, refunds), Meta WhatsApp Cloud API v20.0 (approved templates only), YouTube Data API v3 (`videos.update`, 50 quota units/call), Flutter + supabase_flutter + Riverpod + go_router, SQL assertion scripts (psql DO blocks), `deno test` (jsr std assert + fakes), `flutter_test` widget smoke tests, Node e2e script.

**Depends on:** Master blueprint `docs/superpowers/plans/2026-08-05-church-digital-platform.md` (§2 M1/M2/M3, §5, §6, §8 Phase 1) and `docs/superpowers/plans/2026-08-05-phase0-foundations.md` (Phase 0 created: `supabase start` local stack, monorepo, migrations 0001–0003 with §5 schema incl. `bookings`, `payments`, `waiting_list`, `audit_log`, `public.users`, helpers `current_user_role()`, `tenant_id()`, RLS baseline, RBAC seed, apps/mobile + apps/admin Flutter scaffolds with go_router/Riverpod/supabase_flutter, login screens, CI).

**Assumptions (new templates & columns beyond locked lists — flagged for church admin):**
1. Two WhatsApp templates are ADDED to the locked six for the booking flow: `booking_payment_received` (payment arrived, "we will call you") and `booking_offer` (waiting-list promotion). All eight go to Meta's approval queue in Phase 0's template submission.
2. `payments.merchant_order_id` (text) and `payments.video_id` (bigint, nullable) are new columns added by Phase 1 migrations; `payments.booking_id` is made nullable (video payments have none).
3. `waiting_list.status` uses `'WAITING' | 'OFFERED'` (phase0 left it generic).
4. `faq` table (not in §5) is created in 0004 as the source for `v_faq`.
5. `whatsapp_optins` is created in 0008 (book_slot needs it), `whatsapp_outbox` in 0012 (apply_payment needs it); 0014 hardens both per conventions. Cron jobs read `SUPABASE_URL`/`SERVICE_ROLE_KEY` from `supabase_vault`.

**Migration numbering:** Phase 0 owns 0001–0003. Phase 1 uses 0004–0020 (0009 and 0021 are test scripts, not migrations), applied in order; each SQL task runs `supabase db reset` before its tests.

```sql
-- 0004: portal read views + faq table + RLS (public read, ADMIN/PRIEST write)
create table if not exists public.faq (
  id bigint generated always as identity primary key,
  question_ar text not null,
  answer_ar text not null,
  position int not null default 0,
  published boolean not null default true,
  tenant_id bigint not null default public.tenant_id()
);
alter table public.faq enable row level security;

drop policy if exists "faq public read" on public.faq;
create policy "faq public read" on public.faq for select to anon, authenticated
  using (published = true and tenant_id = public.tenant_id());
drop policy if exists "faq admin write" on public.faq;
create policy "faq admin write" on public.faq for all to authenticated
  using (public.current_user_role() in ('ADMIN','PRIEST','SUPER_ADMIN') and tenant_id = public.tenant_id())
  with check (public.current_user_role() in ('ADMIN','PRIEST','SUPER_ADMIN') and tenant_id = public.tenant_id());

drop policy if exists "services public read" on public.services;
create policy "services public read" on public.services for select to anon, authenticated
  using (tenant_id = public.tenant_id());
drop policy if exists "services admin write" on public.services;
create policy "services admin write" on public.services for all to authenticated
  using (public.current_user_role() in ('ADMIN','PRIEST','SUPER_ADMIN') and tenant_id = public.tenant_id())
  with check (public.current_user_role() in ('ADMIN','PRIEST','SUPER_ADMIN') and tenant_id = public.tenant_id());

drop policy if exists "priests public read" on public.priests;
create policy "priests public read" on public.priests for select to anon, authenticated
  using (tenant_id = public.tenant_id());
drop policy if exists "priests admin write" on public.priests;
create policy "priests admin write" on public.priests for all to authenticated
  using (public.current_user_role() in ('ADMIN','PRIEST','SUPER_ADMIN') and tenant_id = public.tenant_id())
  with check (public.current_user_role() in ('ADMIN','PRIEST','SUPER_ADMIN') and tenant_id = public.tenant_id());

-- views: security_invoker so base-table RLS applies; explicit columns only (no SELECT *)
drop view if exists public.v_services;
create view public.v_services with (security_invoker = true) as
select s.id, s.title_ar, s.description, s.location,
       min(sl.starts_at) filter (where sl.status <> 'CLOSED' and sl.starts_at > now()) as next_slot_starts_at,
       min(sl.price) filter (where sl.status <> 'CLOSED' and sl.starts_at > now()) as price_from,
       s.tenant_id
from public.services s
left join public.service_slots sl on sl.service_id = s.id
where s.tenant_id = public.tenant_id()
group by s.id;

drop view if exists public.v_priests;
create view public.v_priests with (security_invoker = true) as
select id, name, photo_url, bio, visitation_hours, tenant_id
from public.priests
where tenant_id = public.tenant_id();

drop view if exists public.v_faq;
create view public.v_faq with (security_invoker = true) as
select id, question_ar, answer_ar, position
from public.faq
where published = true and tenant_id = public.tenant_id()
order by position;

drop view if exists public.v_schedule_today;
create view public.v_schedule_today with (security_invoker = true) as
select sl.id as slot_id, s.title_ar, sl.starts_at, sl.ends_at, sl.location,
       case when b.id is null then 'AVAILABLE' else 'BOOKED' end as display_status
from public.service_slots sl
join public.services s on s.id = sl.service_id
left join public.bookings b on b.slot_id = sl.id and b.status in ('PENDING_PAYMENT','AWAITING_CALL','CONFIRMED')
where sl.starts_at >= date_trunc('day', now())
  and sl.starts_at <  date_trunc('day', now()) + interval '1 day'
  and sl.status <> 'CLOSED'
  and sl.tenant_id = public.tenant_id()
order by sl.starts_at;
```

```sql
-- 0026: complaints crypto in-DB (replaces complaints-encrypt/decrypt edge functions)
create or replace function public.submit_complaint_secure(p_category text, p_body text)
returns bigint language plpgsql security definer set search_path = public, extensions as $
declare
  v_user uuid := auth.uid();
  v_key text;
  v_id bigint;
begin
  if v_user is null then raise exception 'AUTH_REQUIRED' using errcode = '28000'; end if;
  if p_category is null or p_body is null or length(p_body) > 4000
  then raise exception 'BAD_REQUEST'; end if;
  select decrypted_secret into v_key from vault.decrypted_secrets where name = 'COMPLAINTS_KEY' limit 1;
  if v_key is null then raise exception 'COMPLAINTS_KEY_NOT_SET'; end if;
  insert into public.complaints (user_id, category, body_encrypted, tenant_id)
  values (v_user, p_category, pgp_sym_encrypt(p_body, v_key), public.tenant_id())
  returning id into v_id;
  return v_id;
end $;

create or replace function public.decrypt_complaint(p_complaint_id bigint)
returns text language plpgsql security definer set search_path = public, extensions as $
declare
  v_role text := public.current_user_role();
  v_row public.complaints;
  v_key text;
begin
  select * into v_row from public.complaints where id = p_complaint_id;
  if v_row is null then raise exception 'COMPLAINT_NOT_FOUND'; end if;
  -- mirror v_complaints (0005): admin/super, or the assigned user (priest only when assigned)
  if v_role not in ('ADMIN','SUPER_ADMIN') and v_row.assigned_to <> auth.uid()
  then raise exception 'FORBIDDEN' using errcode = '42501'; end if;
  select decrypted_secret into v_key from vault.decrypted_secrets where name = 'COMPLAINTS_KEY' limit 1;
  if v_key is null then raise exception 'COMPLAINTS_KEY_NOT_SET'; end if;
  return pgp_sym_decrypt(v_row.body_encrypted, v_key)::text;
end $;

grant execute on function public.submit_complaint_secure(text, text) to authenticated;
grant execute on function public.decrypt_complaint(bigint) to authenticated, service_role;

-- dev key for local stack (production sets it in the dashboard once, per conventions)
insert into vault.secrets (name, secret) values ('COMPLAINTS_KEY', 'dev-only-complaints-key')
on conflict (name) do nothing;
```

```dart
class PortalRepository {
  PortalRepository(this._db);
  final dynamic _db; // SupabaseClient (or FakeSupabase in tests)

  Future<List<Map<String, dynamic>>> todaySchedule() async {
    final rows = await _db.from('v_schedule_today').select().order('starts_at');
    return rows.map((r) => Map<String, dynamic>.from(r)).toList();
  }

  Future<List<Map<String, dynamic>>> announcements() async {
    final rows = await _db.from('announcements')
        .select('title_ar, body_ar').order('published_at', ascending: false);
    return rows.map((r) => Map<String, dynamic>.from(r)).toList();
  }
}
```

```sql
-- 0007: availability view. Capacity-aware (multi-seat Mass slots and single-seat
-- funeral slots both work). The lock is NOT a unique index: book_slot() serializes
-- on the service_slots row via SELECT ... FOR UPDATE, then counts active bookings
-- against capacity (see 0008). This view only reports availability.

drop view if exists public.v_available_slots;
create view public.v_available_slots with (security_invoker = true) as
with active as (
  select slot_id, count(*) as active_count
  from public.bookings
  where status in ('PENDING_PAYMENT','AWAITING_CALL','CONFIRMED')
    and (status <> 'PENDING_PAYMENT' or locked_until > now())
  group by slot_id
)
select s.id as slot_id, s.service_id, sv.title_ar, s.starts_at, s.ends_at,
       s.capacity, s.price, s.location,
       coalesce(a.active_count, 0) as booked_count,
       greatest(s.capacity - coalesce(a.active_count, 0), 0) as available_seats,
       case
         when s.status = 'CLOSED' then 'CLOSED'
         when s.starts_at <= now() then 'CLOSED'
         when coalesce(a.active_count, 0) >= s.capacity then 'BOOKED'
         else 'AVAILABLE'
       end as slot_status
from public.service_slots s
join public.services sv on sv.id = s.service_id
left join active a on a.slot_id = s.id
where s.tenant_id = public.tenant_id();
```

```sql
create or replace function public.enforce_booking_status_transition() returns trigger
language plpgsql as $$
begin
  if old.status = new.status then return new; end if;
  if not (
    (old.status = 'PENDING_PAYMENT' and new.status in ('AWAITING_CALL','CANCELLED','RESCHEDULED')) or
    (old.status = 'AWAITING_CALL'    and new.status in ('CONFIRMED','CANCELLED','RESCHEDULED')) or
    (old.status = 'CONFIRMED'        and new.status in ('COMPLETED','CANCELLED','RESCHEDULED'))

  end if;
  return new;
end $$;

-- Multi-seat fix: the v1 unique index (uq_active_booking_per_slot) allowed only ONE
-- booking per slot, breaking Mass slots with capacity > 1. The lock is now: SELECT
-- ... FOR UPDATE on service_slots + atomic capacity count (concurrent bookers
-- serialize on the slot row lock). Same-user same-slot is rejected explicitly.

create or replace function public.book_slot(p_slot_id bigint, p_opt_in boolean default false)
returns public.bookings language plpgsql security definer set search_path = public as $$
declare
  v_user uuid := auth.uid();
  v_role text := public.current_user_role();
  v_phone text;
  v_slot public.service_slots;
  v_active int;
  v_mine int;
  v_book public.bookings;
begin
  if v_user is null then raise exception 'AUTH_REQUIRED' using errcode = '28000'; end if;
  if v_role not in ('PARISHIONER','ADMIN','PRIEST') then raise exception 'FORBIDDEN' using errcode = '42501'; end if;
  select * into v_slot from public.service_slots where id = p_slot_id for update;
  if v_slot is null or v_slot.status = 'CLOSED' or v_slot.starts_at <= now()
  then raise exception 'SLOT_UNAVAILABLE' using errcode = 'P0001'; end if;
  -- anti-abuse: max 3 open PENDING_PAYMENT bookings per user (thundering-herd guard)
  select count(*) into v_mine from public.bookings
  where user_id = v_user and status in ('PENDING_PAYMENT','AWAITING_CALL','CONFIRMED');
  if v_mine >= 3 then raise exception 'TOO_MANY_ACTIVE_BOOKINGS' using errcode = 'P0001'; end if;
  -- same user on the same slot (multi-seat slots)
  if exists (select 1 from public.bookings
             where slot_id = p_slot_id and user_id = v_user
               and status in ('PENDING_PAYMENT','AWAITING_CALL','CONFIRMED'))
  then raise exception 'ALREADY_BOOKED_SLOT' using errcode = 'P0001'; end if;
  -- capacity check under the FOR UPDATE row lock (serializes concurrent bookers)
  select count(*) into v_active from public.bookings
  where slot_id = p_slot_id and status in ('PENDING_PAYMENT','AWAITING_CALL','CONFIRMED')
    and (status <> 'PENDING_PAYMENT' or locked_until > now());
  if v_active >= v_slot.capacity then raise exception 'SLOT_FULL' using errcode = 'P0001'; end if;
  if p_opt_in then
    select phone into v_phone from public.users where id = v_user;
    if v_phone is not null then
      insert into public.whatsapp_optins (phone, source) values (v_phone, 'BOOKING')
      on conflict (phone) do update set consented_at = now();
    end if;
  end if;
  insert into public.bookings (slot_id, user_id, status, locked_until, created_by, tenant_id)
  values (p_slot_id, v_user, 'PENDING_PAYMENT', now() + interval '20 minutes', 'system', public.tenant_id())
  returning * into v_book;
  insert into public.audit_log (user_id, action, entity_type, entity_id, meta)
  values (v_user, 'book_slot', 'bookings', v_book.id,
          jsonb_build_object('slot_id', p_slot_id, 'opt_in', p_opt_in));
  return v_book;
end $$;

create or replace function public.cancel_booking(p_booking_id bigint)

create or replace function public.join_waiting_list(p_slot_id bigint)
returns void language plpgsql security definer set search_path = public as $$
declare v_user uuid := auth.uid();
begin
  if v_user is null then raise exception 'AUTH_REQUIRED' using errcode = '28000'; end if;
  if exists (select 1 from public.bookings where slot_id = p_slot_id
             and status in ('PENDING_PAYMENT','AWAITING_CALL','CONFIRMED'))
  then
    insert into public.waiting_list (slot_id, user_id, position, status, tenant_id)
    select p_slot_id, v_user, coalesce(max(position),0) + 1, 'WAITING', public.tenant_id()
    from public.waiting_list where slot_id = p_slot_id;
    insert into public.audit_log (user_id, action, entity_type, entity_id, meta)
    values (v_user, 'join_waiting_list', 'waiting_list', p_slot_id, '{}'::jsonb);
  else
    raise exception 'SLOT_AVAILABLE: no need to wait';
  end if;
end $$;

create or replace function public.promote_waiting_list(p_slot_id bigint)
returns void language plpgsql security definer set search_path = public as $$
declare
  v_wait record;
  v_book public.bookings;
  v_slot public.service_slots;
begin
  select * into v_wait from public.waiting_list
  where slot_id = p_slot_id and status = 'WAITING' order by position limit 1;
  if v_wait is null then return; end if;
  begin
    -- capacity-aware promotion: lock the slot, count active bookings (same semantics
    -- as book_slot — no unique index exists anymore)
    select * into v_slot from public.service_slots where id = p_slot_id for update;
    if v_slot is null or v_slot.status = 'CLOSED' then return; end if;
    if (select count(*) from public.bookings
        where slot_id = p_slot_id and status in ('PENDING_PAYMENT','AWAITING_CALL','CONFIRMED'))
       >= v_slot.capacity then return; end if; -- slot full again; leave waiting list untouched
    insert into public.bookings (slot_id, user_id, status, locked_until, created_by, tenant_id)
    values (p_slot_id, v_wait.user_id, 'PENDING_PAYMENT', now() + interval '10 minutes', 'system', public.tenant_id())
    returning * into v_book;
  end;
  update public.waiting_list set status = 'OFFERED' where id = v_wait.id;
  insert into public.audit_log (user_id, action, entity_type, entity_id, meta)
  values (null, 'promote_waiting_list', 'bookings', v_book.id,
          jsonb_build_object('waiting_list_id', v_wait.id));
end $$;
```

```sql
create or replace function public.expire_stale_bookings() returns int
language plpgsql security definer set search_path = public as $$
declare
  r record;
  n int := 0;
begin
  for r in
    select id, slot_id from public.bookings
    where status = 'PENDING_PAYMENT' and locked_until < now()
  loop
    update public.bookings set status = 'CANCELLED' where id = r.id;

    n := n + 1;
  end loop;
  return n;
```

```sql
alter table public.payments add column if not exists merchant_order_id text;

-- status enum extension: REFUND_PENDING marks a payment waiting for the paymob-refund edge fn
alter table public.payments drop constraint if exists payments_status_check;
alter table public.payments add constraint payments_status_check check (
  status in ('CREATED','PENDING','PAID','FAILED','REFUNDED','REFUND_PENDING')

-- idempotency key per conventions: gateway_ref unique (NULLs allowed for CREATED rows)
create unique index if not exists uq_payments_gateway_ref
  on public.payments (gateway_ref) where gateway_ref is not null;

-- refund queue: drained by paymob-refund edge fn (Task 23); created here because
-- apply_payment must be able to enqueue refunds on late webhooks
create table if not exists public.refund_requests (
  id bigint generated always as identity primary key,
  payment_id bigint not null references public.payments(id) on delete cascade,
  amount numeric(10,2) not null,
  status text not null default 'PENDING',
  attempts int not null default 0,
  next_attempt_at timestamptz not null default now(),
  created_at timestamptz not null default now()
);
create unique index if not exists uq_refund_requests_payment on public.refund_requests (payment_id);
alter table public.refund_requests enable row level security;

  id bigint generated always as identity primary key,
  phone text not null,
  template_name text not null,
  params jsonb not null default '{}'::jsonb,
  status text not null default 'PENDING',
  attempts int not null default 0,
  next_attempt_at timestamptz not null default now(),
  created_at timestamptz not null default now()
);
alter table public.whatsapp_outbox enable row level security;

returns void language plpgsql security definer set search_path = public as $$
declare
  v_pay public.payments;
  v_book public.bookings;
  v_phone text;
begin
  select * into v_pay from public.payments where id = p_payment_id for update;

      insert into public.refund_requests (payment_id, amount) values (v_pay.id, v_pay.amount)
      on conflict (payment_id) do nothing;
      insert into public.audit_log (user_id, action, entity_type, entity_id, meta)
      values (null, 'auto_refund_late_webhook', 'payments', v_pay.id,
```

```ts
import { createClient } from "npm:@supabase/supabase-js@2";

export interface Deps {
  getClient(): unknown;
  hmacKey: string;
  applyPayment: (paymentId: number) => Promise<void>;
}

// Paymob documented HMAC algorithm: SHA-512 over the 20-field fixed transaction list
// (in this exact order; booleans as lowercase 'true'/'false'; empty string for missing).
export function buildHmacPayload(t: Record<string, unknown>): string {
  const o = t.order as Record<string, unknown>;
  const s = t.source_data as Record<string, unknown>;
  const str = (v: unknown) => v == null ? "" : String(v);
  return [
    t.amount_cents, t.created_at, t.currency, t.error_occured, t.has_parent_transaction,
    t.id, t.integration_id, t.is_3d_secure, t.is_auth, t.is_capture,
    t.is_refunded, t.is_standalone_payment, t.is_voided, o.id, t.owner,
    t.pending, s.pan, s.sub_type, s.type, t.success,
  ].map(str).join("");
}

async function sha512Hex(s: string): Promise<string> {
  const buf = await crypto.subtle.digest("SHA-512", new TextEncoder().encode(s));
  return [...new Uint8Array(buf)].map(x => x.toString(16).padStart(2, "0")).join("");
}

// constant-time hex compare (no early exit on length/content mismatch)
function safeEqual(a: string, b: string): boolean {
  if (a.length !== b.length) return false;
  let diff = 0;
  for (let i = 0; i < a.length; i++) diff |= a.charCodeAt(i) ^ b.charCodeAt(i);
  return diff === 0;
}

export async function handleRequest(req: Request, deps: Deps): Promise<Response> {
  const cors = { "Access-Control-Allow-Origin": "*", "Access-Control-Allow-Headers": "content-type" };
  if (req.method === "OPTIONS") return new Response("ok", { headers: cors });
  try {
    const raw = await req.text();
    const txn = JSON.parse(raw) as Record<string, unknown>;
    // Paymob sends the HMAC as the ?hmac= query parameter on the callback URL (not a header)
    const received = new URL(req.url).searchParams.get("hmac") ?? "";
    const expected = await sha512Hex(buildHmacPayload(txn));
    if (!safeEqual(expected, received)) return new Response(JSON.stringify({ error: "BAD_HMAC" }), { status: 401, headers: cors });

    const supabase = deps.getClient() as ReturnType<typeof createClient>;
    const merchantOrderId = String((txn.order as Record<string, unknown>).merchant_order_id);
    const paid = Boolean(txn.success);
    // idempotent: locate by our merchant_order_id (set at checkout); replay-safe via unique gateway_ref
    const { data: existing } = await supabase.from("payments")
      .select("id, gateway_ref, status").eq("merchant_order_id", merchantOrderId).maybeSingle();
    let pay: { id: number; status: string };
    if (existing) {
      const { data: updated, error: uErr } = await supabase.from("payments")
        .update({ gateway_ref: txn.id, status: paid ? "PAID" : "FAILED", raw_webhook: txn })
        .eq("id", existing.id).select().single();
      if (uErr) throw uErr;
      pay = updated as { id: number; status: string };
    } else {
      const { data: created, error: cErr } = await supabase.from("payments").insert({
        booking_id: null, gateway_ref: txn.id, amount: Number(txn.amount_cents) / 100,
        status: paid ? "PAID" : "FAILED", raw_webhook: txn,
      }).select().single();
      if (cErr) throw cErr;
      pay = created as { id: number; status: string };
    }
    if (paid && pay.status === "PAID") await deps.applyPayment(pay.id);
    return new Response(JSON.stringify({ ok: true }), { status: 200, headers: cors });
  } catch (e) {
    console.error("paymob-webhook error", e);
    return new Response(JSON.stringify({ error: "INTERNAL" }), { status: 500, headers: cors });
  }
}
```

```ts
export interface Deps {
  getClient(): unknown;
  fetch: typeof fetch;
  paymobApiKey: string;

export async function handleRequest(_req: Request, deps: Deps): Promise<Response> {
  const cors = { "Access-Control-Allow-Origin": "*" };
  try {
    const supabase = deps.getClient() as ReturnType<typeof createClient>;
    const { data: bookings, error } = await supabase.from("bookings")
      .select("id, paid_amount")
      .eq("status", "PENDING_PAYMENT")
      .lt("locked_until", new Date(Date.now() - 24 * 3600 * 1000).toISOString());
    if (error) throw error;
    const { data: pays, error: pErr } = await supabase.from("payments")
      .select("id, booking_id, merchant_order_id").eq("status", "CREATED");
    if (pErr) throw pErr;
    const authToken = (await (await deps.fetch("https://accept.paymob.com/api/auth/tokens", {
      method: "POST", headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ api_key: deps.paymobApiKey }),
    })).json()).token;
    let resolved = 0;
    for (const pay of pays) {
      const stale = bookings.some((b) => b.id === pay.booking_id);
      if (!stale) continue;
      const res = await deps.fetch(`https://accept.paymob.com/api/ecommerce/orders/${pay.merchant_order_id}`, {
        headers: { "Content-Type": "application/json", "Authorization": `Bearer ${authToken}` },
      });
      const order = await res.json();
      const paid = (order.transactions ?? []).some((t: { success?: boolean }) => t.success);
      if (paid) { await deps.applyPayment(pay.id as number); resolved++; }
      else {
        await supabase.rpc("cancel_booking", { p_booking_id: pay.booking_id });
        await supabase.from("payments").update({ status: "FAILED" }).eq("id", pay.id);
        resolved++;
      }
    }
    return new Response(JSON.stringify({ ok: true, resolved }), { status: 200, headers: cors });
  } catch (e) {
    console.error("reconcile error", e);
    return new Response(JSON.stringify({ error: "INTERNAL" }), { status: 500, headers: cors });
  }
}
```

```ts
import { createClient } from "npm:@supabase/supabase-js@2";

export const TEMPLATES: Record<string, { paramCount: number }> = {
  booking_confirmed: { paramCount: 1 },      // {{1}} = booking id
  payment_received: { paramCount: 1 },       // {{1}} = YouTube link
  booking_cancelled: { paramCount: 0 },
  booking_rescheduled: { paramCount: 2 },    // {{1}} = old date, {{2}} = new date
  booking_apology: { paramCount: 1 },        // {{1}} = booking id
  otp_auth: { paramCount: 1 },               // {{1}} = OTP code
  booking_payment_received: { paramCount: 2 }, // {{1}} = booking id, {{2}} = amount
  booking_offer: { paramCount: 1 },          // {{1}} = slot date
};

export interface Deps {
  getClient(): unknown;
  fetch: typeof fetch;
  phoneId: string;
  maxAttempts: number;
}

export async function handleRequest(_req: Request, deps: Deps): Promise<Response> {
  const cors = { "Access-Control-Allow-Origin": "*" };
  try {
    const supabase = deps.getClient() as ReturnType<typeof createClient>;
    const { data: queue, error } = await supabase.from("whatsapp_outbox")
      .select("id, phone, template_name, params, attempts")
      .eq("status", "PENDING")
      .lte("next_attempt_at", new Date().toISOString())
      .order("created_at", { ascending: true })
      .limit(100);   // 100/min drain (~6k/hr) covers Feast-scale peaks of ~3.6k msgs/hr

    let sent = 0;
    // parallel dispatch in small batches so a slow Meta call cannot stall the queue;
    // pg_cron granularity is 1 minute, so per-run throughput is the lever
    const batchSize = 10;
    for (let i = 0; i < queue.length; i += batchSize) {
      const batch = queue.slice(i, i + batchSize);
      const results = await Promise.all(batch.map(async (row) => {
        const tmpl = TEMPLATES[row.template_name];
        if (!tmpl) { await fail(supabase, row.id); return 0; }
        const { data: optin } = await supabase.from("whatsapp_optins").select("phone").eq("phone", row.phone).maybeSingle();
        if (!optin) { await fail(supabase, row.id); return 0; }

        const bodyParams = Array.from({ length: tmpl.paramCount }, (_, i) => ({
          type: "text", text: String(Object.values(row.params as Record<string, unknown>)[i] ?? ""),
        }));
        const payload = {
          messaging_product: "whatsapp", to: row.phone, type: "template",
          template: { name: row.template_name, language: { code: "ar" }, components: [{ type: "body", parameters: bodyParams }] },
        };
        const res = await deps.fetch(`https://graph.facebook.com/v20.0/${deps.phoneId}/messages`, {
          method: "POST",
          headers: { "Content-Type": "application/json", "Authorization": `Bearer ${Deno.env.get("WHATSAPP_TOKEN")}` },
          body: JSON.stringify(payload),
        });
        if (res.ok) {
          await supabase.from("whatsapp_outbox").update({ status: "SENT", attempts: row.attempts + 1 }).eq("id", row.id);
          return 1;
        } else if (res.status >= 400 && res.status < 500) {
          await fail(supabase, row.id); // permanent (template rejected, wrong number, ...)
          return 0;
        } else {
          const attempts = row.attempts + 1;
          if (attempts >= deps.maxAttempts) await fail(supabase, row.id);
          else {
            const backoffMs = 30_000 * Math.pow(2, attempts); // 30s, 60s, 120s, 240s
            await supabase.from("whatsapp_outbox").update({
              attempts, next_attempt_at: new Date(Date.now() + backoffMs).toISOString(),
            }).eq("id", row.id);
          }
          return 0;
        }
      }));
      sent += results.reduce((a, b) => a + b, 0);
    }
    return new Response(JSON.stringify({ ok: true, sent }), { status: 200, headers: cors });
  } catch (e) {
    console.error("whatsapp-sender error", e);
    return new Response(JSON.stringify({ error: "INTERNAL" }), { status: 500, headers: cors });
  }
}

async function fail(supabase: ReturnType<typeof createClient>, id: number): Promise<void> {
  await supabase.from("whatsapp_outbox").update({ status: "FAILED" }).eq("id", id);
}

Deno.serve((req) => handleRequest(req, {
  getClient: () => createClient(Deno.env.get("SUPABASE_URL")!, Deno.env.get("SUPABASE_SERVICE_ROLE_KEY")!, { auth: { persistSession: false } }),
  fetch, phoneId: Deno.env.get("WHATSAPP_PHONE_ID")!, maxAttempts: 5,
}));
```

```sql
declare
```

```sql
  v_slot_new public.service_slots;
```

```ts
import { createClient } from "npm:@supabase/supabase-js@2";

export interface Deps {
  getClient(): unknown;
  fetch: typeof fetch;
  paymobApiKey: string;
  amountMultiplier: number;
}

export async function handleRequest(_req: Request, deps: Deps): Promise<Response> {
  const cors = { "Access-Control-Allow-Origin": "*" };
  try {
    const supabase = deps.getClient() as ReturnType<typeof createClient>;
    const { data: requests, error } = await supabase.from("refund_requests")
      .select("id, payment_id, amount, attempts")
      .eq("status", "PENDING")
      .lte("next_attempt_at", new Date().toISOString())
      .limit(50);
    if (error) throw error;
    const { token } = await (await deps.fetch("https://accept.paymob.com/api/auth/tokens", {
      method: "POST", headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ api_key: deps.paymobApiKey }),
    })).json();
    let refunded = 0;
    for (const r of requests) {
      const { data: pay } = await supabase.from("payments").select("gateway_ref").eq("id", r.payment_id).single();
      if (!pay?.gateway_ref) { await setStatus(supabase, r.id, "FAILED"); continue; }
      const res = await deps.fetch("https://accept.paymob.com/api/acceptance/void_refund/refund", {
        method: "POST", headers: { "Content-Type": "application/json" },
        // amount is stored in EGP (0012: numeric(10,2)); Paymob wants cents
        body: JSON.stringify({ auth_token: token, transaction_id: pay.gateway_ref, amount_cents: Math.round(Number(r.amount) * deps.amountMultiplier) }),
      });
      if (res.ok) {
        await setStatus(supabase, r.id, "PROCESSED");
        await supabase.from("payments").update({ status: "REFUNDED" }).eq("id", r.payment_id);
        refunded++;
      } else if (r.attempts + 1 >= 3) {
        await setStatus(supabase, r.id, "FAILED");
      } else {
        await supabase.from("refund_requests").update({ attempts: r.attempts + 1 }).eq("id", r.id);
      }
    }
    return new Response(JSON.stringify({ ok: true, refunded }), { status: 200, headers: cors });
  } catch (e) {
    console.error("paymob-refund error", e);
    return new Response(JSON.stringify({ error: "INTERNAL" }), { status: 500, headers: cors });
  }
}

async function setStatus(supabase: ReturnType<typeof createClient>, id: number, status: string): Promise<void> {
  await supabase.from("refund_requests").update({ status }).eq("id", id);
}

Deno.serve((req) => handleRequest(req, {
  getClient: () => createClient(Deno.env.get("SUPABASE_URL")!, Deno.env.get("SUPABASE_SERVICE_ROLE_KEY")!, { auth: { persistSession: false } }),
  fetch, paymobApiKey: Deno.env.get("PAYMOB_API_KEY")!, amountMultiplier: 100,
}));
```

```dart
class MyBookingsController {
```

```ts
import { createClient } from "npm:@supabase/supabase-js@2";

export interface Deps {
  getClient(): unknown;
  fetch: typeof fetch;
  clientId: string;
  clientSecret: string;
  refreshToken: string;
}

export async function handleRequest(_req: Request, deps: Deps): Promise<Response> {
  const cors = { "Access-Control-Allow-Origin": "*" };
  try {
    const supabase = deps.getClient() as ReturnType<typeof createClient>;
    // videos.update needs OAuth2 (API key is rejected for write ops) — exchange once per run
    const tokRes = await deps.fetch("https://oauth2.googleapis.com/token", {
      method: "POST",
      headers: { "Content-Type": "application/x-www-form-urlencoded" },
      body: new URLSearchParams({
        grant_type: "refresh_token",
        client_id: deps.clientId,
        client_secret: deps.clientSecret,
        refresh_token: deps.refreshToken,
      }),
    });
    if (!tokRes.ok) throw new Error(`OAUTH_TOKEN_HTTP_${tokRes.status}: ${await tokRes.text()}`);
    const accessToken = (await tokRes.json() as { access_token: string }).access_token;

    const { data: videos, error } = await supabase.from("videos")
      .select("id, yt_url, event_date, expires_after_days")
      .eq("privacy", "UNLISTED")
      .not("expires_after_days", "is", null);
    if (error) throw error;
    let flipped = 0;
    for (const v of videos) {
      const expiry = new Date(new Date(v.event_date as string).getTime()
        + (v.expires_after_days as number) * 24 * 3600 * 1000);
      if (expiry > new Date()) continue; // not yet expired
      const videoId = (v.yt_url as string).split("/").pop()?.split("?")[0] ?? "";
      if (!videoId) continue;
      const res = await deps.fetch(
        "https://www.googleapis.com/youtube/v3/videos?part=status",
        {
          method: "PUT",
          headers: { "Content-Type": "application/json", "Authorization": `Bearer ${accessToken}` },
          body: JSON.stringify({ id: videoId, status: { privacyStatus: "PRIVATE" } }),
        },
      );
      if (!res.ok) throw new Error(`YOUTUBE_HTTP_${res.status}: ${await res.text()}`);
      await supabase.from("videos").update({ privacy: "PRIVATE" }).eq("id", v.id);
      flipped++;
    }
    return new Response(JSON.stringify({ ok: true, flipped }), { status: 200, headers: cors });
  } catch (e) {
    console.error("youtube-expiry error", e);
    return new Response(JSON.stringify({ error: "INTERNAL" }), { status: 500, headers: cors });
  }
}
Deno.serve((req) => handleRequest(req, {
  getClient: () => createClient(Deno.env.get("SUPABASE_URL")!, Deno.env.get("SUPABASE_SERVICE_ROLE_KEY")!, { auth: { persistSession: false } }),

  clientSecret: Deno.env.get("GOOGLE_CLIENT_SECRET")!,
```

```sql
do $$
declare
  v_parishioner uuid; v_other uuid; v_admin uuid; v_other_booking bigint; v_amount numeric; v_price int; v_sum numeric;
begin
  select id into v_parishioner from public.users where role='PARISHIONER' limit 1;
  select id into v_other from public.users where role='PARISHIONER' and id <> v_parishioner limit 1;
  select id into v_admin from public.users where role='ADMIN' limit 1;
  -- seed a complaint owned by someone else (as postgres, bypasses RLS; trigger encrypts it)
  insert into public.complaints (user_id, type, message)
  values (v_other, 'OTHER', 'x') on conflict do nothing;
  -- create a booking owned by v_parishioner
  set local role authenticated;
  perform set_config('request.jwt.claims', json_build_object('sub', v_parishioner, 'role','authenticated')::text, true);
  select id into v_other_booking from public.book_slot(
    (select id from public.service_slots where status <> 'CLOSED' and starts_at > now()
       and id not in (select slot_id from public.bookings where status in ('PENDING_PAYMENT','AWAITING_CALL','CONFIRMED')) limit 1),
    false);

  -- 1. PARISHIONER cannot write service_slots, bookings, or payments (RLS filters silently -> assert no change)
  perform set_config('request.jwt.claims', json_build_object('sub', v_other, 'role','authenticated')::text, true);
  select paid_amount into v_amount from public.bookings where id = v_other_booking;
  update public.bookings set paid_amount = paid_amount + 1 where id = v_other_booking;
  if (select paid_amount from public.bookings where id = v_other_booking) <> v_amount
  then raise exception 'FAIL: PARISHIONER must not update others bookings'; end if;
  select price into v_price from public.service_slots limit 1;
  update public.service_slots set price = price + 1;
  if (select price from public.service_slots limit 1) <> v_price
  then raise exception 'FAIL: PARISHIONER must not write service_slots'; end if;
  select sum(amount) into v_sum from public.payments;
  update public.payments set amount = amount + 1;
  if (select sum(amount) from public.payments) is distinct from v_sum
  then raise exception 'FAIL: PARISHIONER must not write payments'; end if;

  -- 2. PARISHIONER cannot see other users' complaints via v_my_complaints
  perform set_config('request.jwt.claims', json_build_object('sub', v_parishioner, 'role','authenticated')::text, true);
  if exists (select 1 from public.v_my_complaints) then

  if exists (select 1 from public.complaints) then raise exception 'FAIL: users must not read complaints table directly'; end if;
```
